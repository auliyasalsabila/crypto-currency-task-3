# Ionic Vue App

A mobile application built with Ionic, Vue 3, TypeScript, and Vite.

## Project setup

```sh
npm install
```

## Development server

```sh
npm run dev
```

Open the local URL printed in the terminal.

## Production build

```sh
npm run build
```

## Preview production build

```sh
npm run preview
```

## Lint and format

```sh
npm run lint
npm run lint:fix
```
